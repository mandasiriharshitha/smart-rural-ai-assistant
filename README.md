🤖 Smart Rural AI Assistant

Overview

Smart Rural AI Assistant is a multi-agent AI system that helps rural communities by providing support for agriculture, education, and government schemes through a simple Streamlit interface.

Features

- 🌾 Agriculture Agent
- 🎓 Education Agent
- 🏛️ Government Schemes Agent
- 🛡️ Safety Agent
- 🧠 Coordinator Agent for intelligent routing
- 🌦️ MCP Weather Tool
- 💬 Streamlit Web Interface

Technologies

- Python
- Streamlit
- Multi-Agent Architecture
- JSON
- MCP Tools

Architecture

User
  ↓
Streamlit UI
  ↓
Coordinator Agent
  ↓
Safety Agent
  ↓
Agriculture | Education | Schemes Agents
  ↓
MCP Tools
  ↓
Response

How to Run

python -m streamlit run app.py
