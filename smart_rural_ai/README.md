# 🤖 Smart Rural AI Assistant

## 📌 Overview
A Multi-Agent AI system designed to assist rural users with agriculture, education, and government schemes using intelligent routing and MCP tools.

---

## 🧠 Problem
Rural users lack access to structured, simple, and intelligent guidance for farming, studies, and government support systems.

---

## 💡 Solution
This project uses a Multi-Agent architecture:

- Safety Agent (filters unsafe queries)
- Agriculture Agent (crop & farming advice)
- Education Agent (concept explanations)
- Schemes Agent (government schemes info)

---

## 🏗️ Architecture

User → Streamlit UI → Coordinator → Safety Agent → Specialized Agent → MCP Tool → Response

---

## 🤖 Key Features

- Multi-Agent System
- Smart Query Routing
- Safety Filtering
- MCP Tool Simulation
- Chat UI using Streamlit
- Memory-based conversation

---

## 🔌 MCP Tools Used
- Weather Tool (mock data)
- Scheme Database (JSON-based knowledge system)

---

## 🎯 Impact
- Helps farmers improve crop decisions
- Helps students understand concepts easily
- Helps users access government schemes

---
